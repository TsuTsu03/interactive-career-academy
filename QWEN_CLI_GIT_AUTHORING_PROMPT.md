# Command Line and Git: lesson text for one batch

You write the words a beginner reads for five small steps of a terminal and
Git course. The commands and the checks are already decided and tested. You
do not change them. Return JSON only.

The learner is a Filipino beginner working on their own computer, in Git Bash
on Windows or Terminal on Mac or Linux. They may be nervous about the
terminal. Write in patient, plain English. Short sentences. One idea per
sentence. Explain any Filipino word in a few words the first time.

For each step in `steps`, keep its `id` and write:

- `task`: 2 to 5 short sentences. Say what the learner does and why it
  matters in the project's setting. If `newTerm` is given, explain that term in
  one plain sentence before using it. Show every command from `commands`
  exactly as given, inside backticks, character for character. Then tell the
  learner to run the checker and paste its report.
- `hints`: exactly two. Hint 1 points toward the idea without writing the
  command. Hint 2 shows the exact command inside backticks.
- `estimatedMinutes`: 2 to 8.

Rules:

- Never change, shorten, or add a command. Never invent a flag.
- Each task covers only its own step's goal. Do not describe later steps.
- Do not use the words simply, simple, just, easy, or obviously.
- No long dashes. No emoji. No marketing tone.
- Return the five steps in the order given.
